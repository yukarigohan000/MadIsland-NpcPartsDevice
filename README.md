# Mad Island — NpcPartsDevice

**NPCの死体・身体パーツの展示・複製と、対応する死亡NPCの蘇生複製ができる「肉体培養槽」を追加するMOD**

[English](README_EN.md) | [ダウンロード](https://github.com/yukarigohan000/MadIsland-NpcPartsDevice/releases/tag/v1.0.11) | [更新履歴](CHANGELOG.md) | [利用条件](RIGHTS.md)

**バージョン：** v1.0.11  
**作者：** yukarigohan

NpcPartsDeviceは、Mad Islandに新しい設備「肉体培養槽」を追加するMODです。NPCの死体や身体パーツを装置内に展示し、素材を使って複製できます。また、条件を満たす死亡NPCから生きたNPCを生成する「蘇生複製」にも対応しています。

同梱の **CorpseCollector** は、通常では死体アイテムを回収できない一部NPCを持ち運べるようにします。

## 主な機能

- **NPCの展示**：死体・身体パーツを培養槽に展示
- **通常複製**：素材を消費して死体や身体パーツを複製
- **蘇生複製**：条件を満たす死亡NPCから生きたNPCを生成
- **死体回収**：一部NPCの死体をアイテムとして回収
- **特殊な姿の再現**：対応する妊娠・欠損・ダルマ状態などを展示
- **一括複製**：1～5個／体をまとめて作成
- **4種類の培養槽**：小型・通常・大型・超大型

## 1. 導入方法

### 必要なもの

- Windows版 Mad Island
- **BepInEx 5.4系（版ごとの確認範囲は下記参照）**
- [本MODの配布ZIP](https://github.com/yukarigohan000/MadIsland-NpcPartsDevice/releases/tag/v1.0.11)

確認基準のゲームは Steam build **25095856** です。ゲームの更新後など、異なる環境での動作は保証できません。BepInEx 6／IL2CPP向けではありません。

| 5.4.23.5 | v1.0.11を開発用ゲームで実機確認済み |
| 5.4.21.0 | 静的API互換性確認済み、実機未確認 |

必要なAPIが互換であれば起動できる設計ですが、BepInEx 5系すべての動作を保証するものではありません。報告者と同じ環境での完全な解決も未確認です。同梱のCorpseCollector v0.3.0は変更していないため、5.4.21.0ではBepInExのバージョン警告が残る可能性があります。バージョン警告と実際の初期化エラーは区別してください。

### インストール

1. ゲームを終了し、念のためセーブデータをバックアップします。
2. [Releases](https://github.com/yukarigohan000/MadIsland-NpcPartsDevice/releases/tag/v1.0.11) から配布ZIPをダウンロードして展開します。
3. 配布ZIP内の `BepInEx` フォルダーを、`Mad Island.exe` があるインストール先へコピーしてください。更新時は `NpcPartsDevice.dll` を上書きしてください。
4. ゲームを起動します。

配置後の例：

```text
Mad Island/
├─ Mad Island.exe
└─ BepInEx/
   └─ plugins/
      ├─ NpcPartsDevice/
      │  └─ NpcPartsDevice.dll
      └─ CorpseCollector/
         └─ CorpseCollector.dll
```

**DLLは2つとも必要です。** 死体回収機能を使わない場合も `CorpseCollector.dll` は外さないでください。CheatMenuなどの別MODは必須ではありません。

**旧個別版から更新する場合：** 以前のNpcPartsDevice本体・Bridge・Ui・Skin・Icons・Animation・NineSlots・Costs・Revive・ModItemJapaneseなど、統合前の関連DLLは `plugins` の外に退避してください。旧版と統合版を同時に読み込ませないでください。

### 既存バージョンからの更新

ゲームを終了し、旧DLLを保管してから、`BepInEx/plugins/NpcPartsDevice/NpcPartsDevice.dll`を本ZIPのv1.0.11で置き換えてください。別フォルダーに旧NpcPartsDevice.dllを残して二重に読み込ませないでください。同梱のCorpseCollector v0.3.0は変更していないため、同版を導入済みならそのまま使用できます。2本構成は引き続き必要です。

## 2. 肉体培養槽の入手・設置

肉体培養槽は、**キャシーのクラフト分類**に追加されます。元の「人造人間製造カプセル」と同じクラフト系統・素材レシピを利用するため、ゲームの進行状況によっては作成できない場合があります。

| 種類 | 用途の目安 |
|---|---|
| 小型 | 小さめのNPC・パーツ |
| 通常 | 一般的なサイズのNPC |
| 大型 | 大きめのNPC |
| 超大型 | とても大きなNPC |

クラフトして設置したら、通常の設備と同じように操作して開きます。装置を複数置くこともできます。小さな培養槽では、大きなNPCの表示がはみ出す場合があります。

## 3. 培養槽の基本操作

装置内には、**複製元1枠・素材3枠・完成品5枠**の合計9スロットがあります。

| スロット | 入れるもの |
|---|---|
| 複製元 | 対応するNPCの死体または身体パーツ（1個） |
| 血肉 | 複製素材の血肉 |
| 母乳 | 複製素材の母乳 |
| 生命のオーブ | 蘇生複製に必要なオーブ |
| 完成品 ×5 | 通常複製で作ったアイテムの受け取り先 |

### 死体・パーツを展示する

1. 培養槽を開きます。
2. 「複製元」スロットに対応する死体または身体パーツを入れます。
3. 装置内に展示されます。

**展示だけでは複製用素材を消費しません。**

### 通常複製する

1. 複製元に死体または身体パーツをセットします。
2. 必要な血肉・母乳を素材スロットに入れます。
3. 完成品5枠を空にします。
4. 個数を **1～5** から選び、「複製」を押します。
5. 演出後、完成品を装置から取り出します。

複製元の死体やパーツは消費されません。

### 蘇生複製する

1. 複製元に**対応する死亡NPCの死体**をセットします（身体パーツ単体からは蘇生できません）。
2. 血肉・母乳・生命のオーブを入れ、完成品5枠を空にします。
3. 数量を **1～5** から選び、「蘇生複製」を押します。
4. 演出後、装置の周辺に生きたNPCが生成されます。

蘇生個体は原本とは別のNPCです。死亡した仲間が適切に登録されている場合は、新しい仲間として登録されます。元々仲間でないNPCが必ず仲間になるわけではありません。生成されたNPCの持ち物・装備は空になります。

**注意：** NPCの状態、仲間登録、保存データなどに問題がある場合、蘇生は実行できません。動作は屋外など十分な空間のある場所で確認してください。

### 必要な素材

| 操作（1個・1体あたり） | 血肉 | 母乳 | 生命のオーブ |
|---|---:|---:|---:|
| NPCパーツ複製 | 50 | 10 | 不要 |
| NPC死体複製 | 100 | 50 | 不要 |
| 蘇生複製 | 300 | 100 | 10 |

数量に比例して素材が必要です。例えば、死体を3個複製する場合は血肉300・母乳150を使用します。操作時にゲーム内で表示される必要量も確認してください。

## 5. 死体回収（CorpseCollector）

通常は死体アイテムを回収できない一部NPCを持ち運べます。実機確認済みの対象は上の表を参照してください。

1. 対応するNPCの死体を調べます。
2. 死体パネルから運搬・回収の操作を行います。
3. 回収した死体をインベントリで保持し、対応する培養槽の展示や複製に利用できます。

インベントリの空きが必要です。生存中・気絶中のNPCは死体回収の対象ではありません。

### 人魚の食材化

人魚の地面上の死体を調べ、専用の「食材化」を選ぶと、死体を消費して魚肉4個を入手できます。持ち物の空きを確保して実行してください。通常の死体回収とは別の操作です。

## 6. 特殊な外見

一部の対応NPCでは、妊娠腹部や手足の欠損、ダルマ状態などの展示・複製を扱えます。NPCや身体状態によっては再現できないことや蘇生できないことがあります。

## 7. セーブデータと注意点

装置の内容はゲーム標準の保存形式を利用します。通常セーブスロット **1～19** を扱う設計ですが、全スロットの動作を実機確認したという意味ではありません。

MOD導入・更新・削除前には、ゲームを終了して**セーブと設定のバックアップ**をおすすめします。特に装置内に死体・素材がある場合や、蘇生したNPCが存在する場合は注意してください。

セーブやロードのエラー、装置の異常が続く場合は、上書き保存を繰り返さず、バックアップからの復旧を検討してください。

## 8. よくある質問

**Q. 培養槽がクラフトに表示されません。**  
キャシーのクラフト分類と、元の人造人間製造カプセルの作成条件を確認してください。

**Q. NPCを培養槽に入れられません。**  
対応NPCかどうか、死体・パーツが必要な個体データを保持しているか確認してください。実機確認済みのIDでも特殊な状態によっては投入できません。

**Q. 「複製」「蘇生複製」ができません。**  
複製元、素材量、完成品5枠の空き、数量、蘇生対象の死亡・仲間登録状態などを確認してください。

**Q. 複製・蘇生したNPCの持ち物がありません。**  
仕様です。新しい個体は原本の所持品・装備を引き継ぎません。

**Q. MODが読み込まれません。**  
BepInEx 5の導入、2本のDLLの配置、旧個別版DLLの重複がないか確認してください。ゲームの更新で互換性が失われる場合もあります。

## 9. アンインストール

1. 可能なら、ゲーム内で装置から死体・素材・完成品を回収します。
2. ゲームを終了し、セーブをバックアップします。
3. `BepInEx/plugins/NpcPartsDevice` と `BepInEx/plugins/CorpseCollector` を `plugins` の外に退避します。

MOD専用アイテムや生成NPCが残るセーブは、MODを外すと正常に使えない可能性があります。必要なら導入前のセーブへ戻してください。
